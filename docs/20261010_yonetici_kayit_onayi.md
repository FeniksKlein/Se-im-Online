# Yönetici onaylı kayıt sistemi (10 Ekim 2026)
Canlı Supabase projesinde oyun_yonetim.kayit_basvurulari tablosu, auth.users kayıt tetikleyicisi, public.kayit_basvur, public.admin_kayit_basvurulari, public.admin_kayit_karar, oyun.ben ve public.durum güncellenmiştir. Mevcut profiller değişmez. Yeni kullanıcı önce e-postasını doğrular ve kullanıcı adı/il belirtir. Başvuru beklemede kalır; yalnızca yöneticinin kabulünden sonra oyun.profiller kaydı oluşturulur. Reddedilen hesapların oyun API erişimi sınırlandırılır. Arayüz kaynakları gelistirici/www/index.html, www/index.html ve docs/index.html olarak güncellendi.
